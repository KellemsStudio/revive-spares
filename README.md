# Revive Spares

Demo website for Revive Spares, a Nissan and VW stripping yard selling quality used parts.

Static HTML, CSS and JavaScript with no build step. Open `index.html`, or serve the folder:

```bash
python -m http.server 5173
```

Stock, prices and contact details live at the top of `assets/js/main.js`.
The photo of Fata (`assets/img/team/fata.jpg`) is a placeholder from Unsplash.
